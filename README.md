# ڕێگای ئیسلام — Telegram Bot

وەشانی Telegram لەسەر بنەمای سەرچاوەی Android ـی `ڕێگای ئیسلام` دروست کراوە. فایلە بنەڕەتییەکانی قورئان و داتابەیسە ئایینییەکان لە ZIP ـی بەکارهێنەرەوە هێنراون و ناوەڕۆکیان بە شێوەی خۆی پارێزراوە.

## تایبەتمەندییە چالاکەکان

- قورئانی پیرۆز: 114 سوڕەت، 6236 ئایەت، خوێندنەوەی ئایەت و پیشاندانی خانەکانی ڕوونکردنەوەی ناو داتابەیس.
- گەڕان لە دەقی قورئان و هەندێک خانەی ڕوونکردنەوە.
- کاتەکانی بانگ بۆ ئەو شارانەی لە `katenwezh62.db` هەن، بە بەرواری ئێستا.
- هەژمارکردنی ئاراستەی قیبلە بۆ ئەو شارانەی کۆئۆردیناتیان هەیە.
- دوعاکان، 100 ناوی خودا، تەسبیحی ئەلیکترۆنی.
- کتێب و فەرموودە، لەوانە 400 فەرموودەی `farmwda.json`.
- بابەتەکانی ڕەمەزان، زیکر، ڕوقیە، ژیانی پێغەمبەران، هاوەڵان، حەج، خەوننامە و بابەتەکانی تری JSON.
- هەڵگرتنی شار و ژمارەی تەسبیحی بەکارهێنەر لە SQLite.
- ⭐ دڵخوازکردنی ئایەتەکانی قورئان و لیستی تایبەتی هەر بەکارهێنەر.
- 🎙️ هەڵبژاردنی قاری و سوڕەت و ناردنی دەنگی تەواوی سوڕەت لە تێلەگرام؛ ئەو قارییانەی لە داتای سەرچاوەدا فۆرماتی لینکی 001.mp3 تا 114.mp3 ـیان پشتڕاست کراوە.
- 📍 تۆمارکردنی دوا شوێنی خوێندنەوە و گەڕانەوە بۆ هەمان لاپەڕە.
- ⚙️ ڕێکخستنی بەکارهێنەر بۆ بینینی شار، ژمارەی تەسبیح و دەستگەیشتن بە دڵخوازەکان.
- پشکنینی ئۆتۆماتیکی syntax و داتاکان لە GitHub Actions لە هەر push ـێکدا.

## جیاوازییە گرنگەکان / سنووردارییەکان

- کاتەکانی بانگ لە خشتەی ساڵانەی سەرچاوەکەوە دەخوێندرێنەوە؛ لەگەڵ مزگەوتی ناوچەکەت بەراوردیان بکە. ئەم خشتەیە لەوانەیە بۆ هەموو ساڵێک نوێ نەکرابێتەوە.
- قیبلە بە کۆئۆردیناتی شار هەژمار دەکرێت، نەک GPS ـی ڕاستەوخۆی بەکارهێنەر.
- Telegram وەک ئەپی Android توانای قطب‌نمای ڕاستەوخۆ، ویجێتی مۆبایل، ئاگادارکردنەوەی ناوخۆی مۆبایل و پەخشکردنی دەنگی بەردەوام نییە. لەم وەشانەدا ئەو بەشانەی پێویستیان بە توانای مۆبایل/سێرڤەری بەردەوام هەیە وەک بەشی چالاک نیشان نەدراون.
- بەشی قارییەکان لە بنکەدراوەی `dangakan.json` لینکی بنەڕەتی دەخوێنێتەوە و ناوی فایلەکە بە ژمارەی سوڕەت (`001.mp3` تا `114.mp3`) دروست دەکات. هەندێک لینکی دەرەکی لەوانەیە لەلایەن Telegram ـەوە ڕاستەوخۆ وەرنەگیرێت؛ لەو حاڵەتەدا دوگمەی کردنەوەی لینکی دەنگ پیشان دەدرێت. مافی بڵاوکردنەوەی دەنگەکان لەگەڵ خاوەن سەرچاوەکان بپشکنە.
- ناوەڕۆکی ئایینی لە سەرچاوەی ئەپەکەوە گوازراوەتەوە؛ ئەم بۆتە فەتوای نوێ یان بڕیاری شەرعی دروست ناکات.

## ڕێکخستنی خۆجێیی

1. Python 3.11 یان نوێتر دابمەزرێنە.
2. `pip install -r requirements.txt`
3. `.env.example` بکۆپیکە بۆ `.env` و `BOT_TOKEN` دابنێ.
4. `python bot.py`

لە GitHub Actions ـدا:

1. پڕۆژەکە بۆ repository ـێکی GitHub push بکە.
2. لە Settings → Secrets and variables → Actions، secret ـێک بە ناوی `BOT_TOKEN` زیاد بکە.
3. بە ئارەزوو `ADMIN_IDS` زیاد بکە (ژمارەی Telegram ID ـی بەڕێوەبەر).
4. لە Actions، workflow ـی `Regay Islam Telegram Bot` دەستپێبکە.

Workflow ـەکە هەر کاتژمێرێک نزیکەی 55 خولەک bot ـەکە بە polling دەخاتە کار. GitHub Actions بۆ bot ـی 24/7 سێرڤەری تایبەت نییە و scheduled run ـەکانیش دەتوانن دوا بکەون؛ بۆ کارکردنی بەردەوام، VPS یان webhook hosting گونجاوترە.

## تایبەتمەندییە نوێ زیادکراوەکان

- `/favorites` — بینین و لابردنی ئایەتە دڵخوازکراوەکان.
- `/lastread` — گەڕانەوە بۆ دوا شوێنی خوێندنەوەی قورئان.
- `/settings` — بینینی ڕێکخستن و گۆڕینی شار.
- دڵخواز و دوا خوێندنەوە لە SQLite هەڵدەگیرێن؛ بۆ هەر Telegram user جیاوازن.

## داتابەیسە سەرەکییەکان

- `regayislam.db` — دەقی قورئان و خانەکانی ڕوونکردنەوە.
- `surat.db` — ناو، ژمارەی ئایەت و زانیاری سوڕەتەکان.
- `katenwezh62.db` — خشتەی کاتەکانی بانگ و شارەکان.
- `mu.db` — کتێب/فەرموودە و بەشەکانیان.
- `name.db` — ناوەکانی خودا.
- `duha.db` — دوعاکان.
- `garanawa.db`, `ramazanew.db`, `rm.db` — بابەتەکانی تەوبە و ڕەمەزان.
- JSON ـەکانی `data/` — فەرموودە، زیکر، ڕوقیە، ژیاننامە و بابەتە جۆراوجۆرەکان.

## تێبینیی پاراستنی نهێنی

هیچ Telegram token یان API key ـێک لە کۆدەکەدا دانەنراوە. Token تەنها لە environment variable / GitHub Secret دابنێ. فایلەکانی secret ـی Android ـی سەرچاوەکە نەگوازراونەتەوە.

## پشکنینی داتا

بۆ پشتڕاستکردنەوەی ژمارەی ڕیزە سەرەکییەکان و دروستی JSON:

```bash
python scripts_check_data.py
```

هەموو 75 فایلە DB ـی بنەڕەتی لە `data/` و `data/recitation_timings/` پارێزراون؛ 27 فایلە JSON و 13 دەنگی خامیش لە پڕۆژەکەدان.

## پاراستنی ناوەڕۆک

داتاکان وەک لە فایلە بارکراوەکەدا بوون گوازراونەتەوە. پێش بڵاوکردنەوەی گشتی، مافی بڵاوکردنەوەی دەق، تەفسیر، دەنگ و کتێبەکان بپشکنە.
